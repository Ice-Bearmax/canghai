数据源

开关写进 sources.local.json（本地覆盖，不动仓库主配置）。加新源 = 丢一个适配器进 core/sources/ 再登记。

如何新增数据源

  1. 在 core/sources/ 新建 my-source.js，实现 id / label / configSpec / fetch(ctx) / normalize(raw)
  2. 在 sources.config.json 的 sources[] 里加一项 { "id":"my", "adapter":"my-source", "enabled":true }
  3. 跑 node cli.js sync --only=my 验证

核心逻辑不认具体数据源，只认接口——所以新增/切换源不需要改任何代码。
